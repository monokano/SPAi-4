About SPAi

What the app does

SPAi (Script Panel Ai) is a script panel for running Adobe Illustrator scripts. It shows the scripts in your registered folders in a panel, keeping their folder hierarchy, and you double-click a script to run it.

SPAi is not a panel built into Illustrator (an extension or plug-in). It is a separate app that runs alongside Illustrator, so it does not appear in Illustrator's Window menu. While SPAi is running, its panel and shortcuts work whenever you use Illustrator.

Running scripts

The script panel is the main way to run scripts. Alongside the panel, you can also use shortcuts and the search palette.

Script panel
Pick a script from the list and double-click it to run it. See Script Panel.
Individual shortcuts
From the panel, you can assign keys to the scripts you use most. Once assigned, you can run a script just by pressing its keys, even when the panel isn't shown. See Shortcuts.
Search palette
When you have so many scripts that one is hard to find in the panel's list, type part of its name to find it, and press Return to run it. You can do everything from the keyboard. See Search Palette.

When SPAi works

SPAi's shortcuts work only while Illustrator is frontmost. While you are using other apps, the shortcuts are inactive and don't interfere with your usual keys. When Illustrator is not frontmost, the menu bar icon appears dimmed.

Scripts are sent to the Illustrator that was most recently frontmost. Even if several versions (including Beta) are running at the same time, scripts run in the version you are working in. The destination is shown at the top of the script panel.

When a script succeeds, nothing is shown; SPAi shows a dialog only when it fails.

Note SPAi needs Automation (Apple Events) permission to control Illustrator. See Permissions and Troubleshooting.

Menu bar and Dock menus

SPAi stays in the menu bar or Dock. The menu bar icon and the Dock icon's menu contain the following items.

Show Panel / Hide Panel
Shows or hides the script panel. From the menu, you can open the panel even while using an app other than Illustrator.
Search Scripts…
Opens the search palette. Unavailable unless Illustrator or SPAi is frontmost.
Settings…
Opens the Settings window.
Help
Shows this help.

Choose whether SPAi appears in the menu bar or the Dock with "Display Mode" in Settings.
