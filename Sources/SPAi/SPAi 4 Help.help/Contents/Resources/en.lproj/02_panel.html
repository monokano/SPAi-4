Script Panel

The script panel is the main window of SPAi. It lists the scripts in your registered folders so you can choose and run them with the mouse. You also assign shortcuts from this panel.

Showing and hiding the panel

  • Press ⌥⇧⌘Space to show or hide the panel. This key works only while Illustrator is frontmost. You can change the key under "Built-in Shortcuts" in the Shortcuts tab of Settings.
  • You can also choose "Show Panel" / "Hide Panel" from the menu.
  • You can also close the panel with the close button.
  • The panel's position and size are remembered, and it appears in the same place the next time you open it.

When "Show Panel Only When Illustrator Is Frontmost" is on in Settings (the default), the panel hides automatically when you switch to another app and reappears when you return to Illustrator.

Note The panel never takes keyboard input. Illustrator's keyboard shortcuts keep working while the panel is shown.

Target Illustrator

The top of the panel shows the version of Illustrator that runs scripts (the most recently frontmost Illustrator). When Illustrator is not running, it shows "Illustrator Not Running."

Buttons at the top of the panel

The right side of the top of the panel has three buttons, from left to right:

Magnifying glass
Opens the search palette. Use it to find a script by name and run it.
Gear
Opens the Settings window.
⌘
Lists only the scripts that have shortcuts. Click it again to return to the normal list. You can run scripts from this list the same way as from the normal list.
By default, this list is sorted by shortcut, which makes it easy to find unused keys. You can sort it by name instead in Settings.

Running scripts

Double-click a script to run it. The panel stays open after running, so you can go on to run another script.

If you set "Run Scripts" to "Single-Click" in Settings, clicking a row runs it. See Settings.

  • To deselect a row, hold down ⌘ and click the selected row, or click an empty area of the list.
  • Aliases show a small arrow at the lower left of the icon.
  • If a folder contains scripts with the same name but different extensions, the extension is shown dimmed after the name.

Opening and closing folders

Scripts are shown per registered folder, keeping the subfolder hierarchy.

  • Click a folder row to open or close it.
  • Option-click (⌥) to open or close all of its subfolders as well.
  • Which folders are open is remembered.

Showing and assigning shortcuts

Scripts with an assigned shortcut show the keys at the right end of the row. Click the keys to change the shortcut. For rows without a shortcut, a ⌘ symbol appears when you move the pointer over the row; click it to assign one. See Shortcuts.

Shortcut menu

Run
Runs the script.
Edit
Opens the script in the same app as double-clicking it in the Finder. Not available for apps (.app).
Assign Shortcut… / Change Shortcut…
Opens the shortcut recording screen.
Remove Shortcut
Removes the assigned shortcut.
Reveal in Finder
Shows the script or folder in the Finder.

Collapsing the panel

Double-click an empty part of the top row of the panel (the row that shows the target Illustrator) to collapse the panel and hide the list. Double-click again to restore its height. The panel stays collapsed even after you quit SPAi.
