Search Palette

The search palette is a window for finding scripts by name and running them. Use it when you have so many scripts that one is hard to find in the script panel's list. You can do everything from the keyboard.

How to use it

  1. Press ⇧⌘Space, or choose "Search Scripts…" from the menu. You can also click the magnifying glass button at the top of the script panel. The palette opens, ready for you to type in the search field.
  2. Type part of a script's name. The results narrow as you type.
  3. Choose a result with ↑ ↓ and press Return to run it. The palette closes when the script runs.

You can also double-click a result to run it. To close without running anything, press Esc, click outside the palette, or press ⇧⌘Space again.

⇧⌘Space and the "Search Scripts…" menu item work only while Illustrator or SPAi is frontmost. You can change the key under "Built-in Shortcuts" in the Shortcuts tab of Settings.

How searching works

  • A script matches if the characters you type appear in its name in the same order, even with other characters in between (fuzzy matching). For example, "ssm" finds "select_same.jsx".
  • Uppercase and lowercase are treated the same. For Japanese text, full-width and half-width characters, and hiragana and katakana, are also treated the same.
  • Scripts are also found by the name of the folder that contains them.
  • When the search field is empty, all scripts are listed with the most recently used first. To run the script you used last, just open the palette and press Return.
Note While text is still being composed in an input method such as Japanese, Return, ↑ ↓, and Esc act on the input method. A script runs only when you press Return after confirming the text.

Position and size

You can drag the palette to move it and resize it. Its position and size are remembered, and it appears in the same place the next time you open it.
