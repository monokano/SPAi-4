Scripts and Registered Folders

Files SPAi can run

ExtendScript (.jsx, .js)
Illustrator scripts. They run in the most recently frontmost Illustrator.
AppleScript (.scpt, .applescript, .scptd)
Run as AppleScript.
Applications (.app)
Opens the application. Applets made with AppleScript can also be run. An application that is already running only comes to the front and does not run again (this is how macOS works).
Important For AppleScript and applets, SPAi can't choose which Illustrator runs the script. When more than one Illustrator (including Beta) is running, the script may run in a version you didn't intend, so SPAi asks for confirmation before running it. Turn on "Don’t show this again until SPAi quits" to skip the confirmation until you quit SPAi.

Registered folders

To run scripts with SPAi, you need to register the folders that contain them. You can add and remove registered folders in Settings, and you can register more than one. When you first open SPAi, the "SPAi 4 Scripts" folder in your Documents folder is registered.

  • All subfolders of a registered folder are included in the list.
  • Adding, deleting, and renaming scripts is reflected in the list automatically.
  • You can change the order of registered folders, and whether each one appears in the panel, in Settings. Within each folder, items are sorted by name.
  • Even when a registered folder is hidden from the panel, shortcuts assigned to its scripts keep working.

What doesn't appear in the list

  • Files of types other than those above.
  • The contents of hidden folders (folders whose names begin with ".") and "node_modules" folders.
  • The contents of folders that a folder alias (or symbolic link) points to. To list the scripts in such a folder, add that folder itself as a registered folder.

Aliases of scripts (files) do appear in the list and run the same way as the original files.

Registered folders on a server

You can also register shared folders on a server. Scripts added or changed on the server from another Mac appear in the list when you open the panel or search palette, or when Illustrator comes back to the front.

Registered folders that can't be found

If you delete a registered folder, move it to the Trash, or disconnect its disk, the list in Settings shows ⚠ and its status ("Trash," "Not Connected," or "Deleted") at the right end of the row. When you put it back from the Trash or reconnect the disk, it appears in the panel's list again.
