Settings

Choose "Settings…" from the menu bar icon or the Dock icon's menu, or click the gear button at the top of the panel, to open the Settings window. The Settings window has four tabs: General, Panel, Folders, and Shortcuts.

General

Display Mode

Choose where SPAi appears: "Menu Bar Only," "Dock Only," or "Menu Bar and Dock."

On a Mac whose built-in display has a notch, "Menu Bar Only" is unavailable, because the menu bar icon can be hidden behind the notch and become impossible to use.

Tip If you can no longer see the menu bar icon, hold down the ⌘ (Command) key while opening SPAi to reset the display mode to the default (Menu Bar and Dock).

Launch at Login

Opens SPAi automatically when you log in to your Mac.

Panel

Script Panel

Show Panel Only When Illustrator Is Frontmost
When this is on (the default), the script panel hides automatically when you switch to another app and reappears when you return to Illustrator. When it is off, the panel stays visible while you use other apps.
List Text Size
Choose the text size of the script panel's list: "Extra Small," "Small," "Medium," or "Large" (the default is "Medium").
Run Scripts
Choose how to run a script in the script panel: "Double-Click" or "Single-Click" (the default is "Double-Click"). With "Single-Click," clicking a script selects and runs it; double-clicking runs it only once. The search palette works the same either way.
Sort Shortcut List by Key
Sorts the script panel's list of scripts that have shortcuts by shortcut (1, 2 … A, B …; shortcuts with the same key are sorted by modifier keys). This is on by default. When it is off, the list is sorted by name. See Script Panel.

Folders

Registered Folders

The folders whose scripts SPAi lists. See Scripts and Registered Folders.

+ button
Choose folders to register. You can also drag folders from the Finder to the list; they're added where you drop them.
− button
Removes the selected folder from the list. The folder itself is not deleted.
Reveal in Finder button
At the right end of each row. Shows that row's folder in the Finder.
Checkbox
Folders that are checked appear in the panel and search palette. Even when unchecked, shortcuts assigned to scripts in the folder keep working.
Order
Drag rows to reorder them. The panel shows registered folders in this order.

Shortcuts

Built-in Shortcuts

Change the shortcuts for the features built into SPAi. They all work only while Illustrator is frontmost.

Show Panel (default ⌥⇧⌘Space)
Shows or hides the script panel.
Search Scripts… (default ⇧⌘Space)
Opens the search palette.
Clean Paste (default ⌥V)
Pastes the clipboard as plain text (see below).
Clean Paste (Trim) (default ⌥⇧V)
Same as Clean Paste, and also removes spaces and line breaks at the beginning and end of the clipboard text.
  • To change a key, click the shortcut field, then press the new keys. The keys you press are registered right away. To cancel, press Esc or click somewhere else.
  • To stop using a shortcut, click ✕ on the right (or click the field and press Delete).
  • The keys you can use are the same as for script shortcuts.
  • If you press a key that is already used by another built-in shortcut or a script, a warning appears. Click "Replace" to remove the shortcut from the other one.
  • Click "Restore Defaults" to set all four back to their default keys. If a default key is assigned to a script, a confirmation appears; restoring removes the shortcut from that script.

Clean Paste

Pastes the clipboard text as plain text, without formatting, into the text you are editing in Illustrator (when characters are selected or the cursor is placed with the Type tool). Selected characters are replaced.

  • Combining characters, such as Japanese voiced sound marks, are composed where possible before pasting. Compatibility ideographs and similar characters are protected so they don't change into other characters.
  • Line breaks are converted to Illustrator paragraph breaks.
  • If characters that can't be composed remain (combining characters that can't be composed, private use characters, flag emoji, or skin tone modifiers), a warning appears. Click "Check" to open a window where you can find those characters one by one with "Next." Click "Paste" to paste anyway.
  • Nothing happens when no document is open or you are not editing text.

Script Shortcuts

Export your assigned shortcuts to a file, or import them. Use these to move your shortcuts from another Mac or from SPAi 3. See Shortcuts.
