Permissions and Troubleshooting

Automation (Apple Events) permission

To run scripts in Illustrator, SPAi needs Automation (Apple Events) permission. The first time you run a script, a dialog asks for permission; choose "Allow."

If you don't allow it, a dialog tells you that the script failed to run. Click "Open System Settings" to open System Settings › Privacy & Security › Automation, and turn on the Illustrator item under SPAi.

Note SPAi does not require Accessibility permission.

Dialogs that report failures

When a script succeeds, nothing is shown. SPAi shows a dialog only in these cases:

  • The script ended with an error. The dialog shows the error returned by Illustrator. However, "Error 1302: No such element" isn't reported when no document is open, because Illustrator doesn't show anything in that case either when you run the script directly.
  • The script couldn't be sent to Illustrator, or the application couldn't be opened.
  • The script wasn't run because the previous script was still running. Run it again after the previous script finishes.

When things don't work

No shortcuts work at all
Check that Illustrator is frontmost. SPAi's shortcuts work only while Illustrator is frontmost.
Scripts don't run
Check the Automation permission (above). If the top of the panel shows "Illustrator Not Running," open Illustrator.
A script doesn't appear in the list
Check that the file type is supported, that it isn't inside a hidden folder or a "node_modules" folder, and that the registered folder's checkbox is on in Settings. See Scripts and Registered Folders.
An assigned shortcut doesn't work
In the panel's list of scripts that have shortcuts (the ⌘ button at the top of the panel), check whether the script appears dimmed with ⚠. Shortcuts whose files can't be found don't work. Also, keys that are used by a macOS keyboard shortcut don't work, because macOS takes priority. See Shortcuts.
A script ran in the wrong version of Illustrator
For AppleScript and applets, SPAi can't choose which Illustrator runs the script. When several versions are running, quit the versions you aren't using before running the script.
The menu bar icon is missing
The display mode may be set to "Dock Only," or the icon may be hidden behind the notch. Hold down ⌘ while opening SPAi to reset the display mode to the default (Menu Bar and Dock).
