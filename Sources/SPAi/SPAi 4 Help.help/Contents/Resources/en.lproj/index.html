SPAi 4 Help

SPAi (Script Panel Ai) is a script panel for Adobe Illustrator. It lists the scripts in your registered folders in a panel, and you double-click a script to run it. You can also assign shortcuts to the scripts you use most, and find scripts by name with the search palette. It is not an Illustrator panel; it runs as a separate app.
